つなぎ方

PC や Mac で動かしている OpenCode に、スマートフォンからつなぐ方法をまとめています。家の中だけで使うなら「同じ Wi-Fi」、外出先からも使うなら「Tailscale」がおすすめです。

まず、サーバーを起動する

どの方法でも、PC/Mac ではパスワードを付けて OpenCode を起動します。

export OPENCODE_SERVER_PASSWORD=好きなパスワード
opencode serve --hostname 0.0.0.0 --port 4096

Windows の PowerShell では $env:OPENCODE_SERVER_PASSWORD="好きなパスワード" で設定してから起動します。アプリの接続画面には、ここで決めたパスワードを入力します（ユーザー名は opencode のままで構いません）。

パスワードなしで起動すると、同じネットワークにいる誰でもあなたの PC を操作できてしまいます。必ず設定してください。

パソコンでも OpenCode を使っている場合

OpenCode はクライアント・サーバー構成です。セッション・権限・質問（フォーム）は「1 つのサーバー」が持ち、デスクトップアプリや opencode（TUI）はそこに接続するクライアントです。パソコンでも使っているときに別の opencode serve を起動するとサーバーが 2 つになり、パソコン側で出た質問や権限がスマートフォンに出ない（逆も同じ）という食い違いが起きます。メッセージ履歴だけは共有されるので、動いているように見えて気づきにくいのが厄介な点です。

この場合は opencode serve ではなく、パソコンがすでに使っている共有サーバー（background service）を外部に公開してください。

opencode service set hostname 0.0.0.0
opencode service restart
opencode service status   # http://0.0.0.0:4096 のように表示されれば OK

ポートを 4096 に固定すると、アプリの自動検出や http://192.168.1.10:4096 の入力がそのまま使えます。

opencode service set port 4096
opencode service restart

パスワードは自動で設定されています。opencode service get password で確認し、アプリに入力してください（opencode serve のときに自分で決めるパスワードとは別です）。

上の「まず、サーバーを起動する」の opencode serve は、そのサーバーだけを使う（パソコンでデスクトップアプリや TUI を使わない）場合の手順です。どちらの場合も、あとから opencode service status で状態を、opencode service restart で再起動を確認できます。

同じ Wi-Fi でつなぐ

スマートフォンと PC が同じ Wi-Fi にあるときの、いちばん簡単な方法です。

  1. 上の手順でサーバーを起動します。
  2. アプリの接続画面を開くと、同じネットワークのサーバーが自動で一覧に出ます。タップしてパスワードを入力します。
  3. 出てこないときは、PC の IP アドレスを調べて http://192.168.1.10:4096 の形で入力します。
    Mac: ipconfig getifaddr en0　Windows: ipconfig　Linux: hostname -I

つながらないときは、PC のファイアウォールでポート 4096 への接続が許可されているかを確認してください。外出先からはこの方法ではつながりません。

Tailscale でつなぐ（外出先からも使える）

Tailscale は、自分の端末どうしを安全な専用ネットワークでつなぐサービスです。個人利用は無料で、ポートをインターネットに開ける必要がありません。

  1. PC/Mac とスマートフォンの両方に Tailscale を入れ、同じアカウントでログインします。
  2. 上の手順でサーバーを起動します。
  3. PC で tailscale ip -4 を実行し、表示された 100. で始まるアドレスを確かめます。
  4. アプリで http://100.x.y.z:4096 の形で入力して接続します。MagicDNS が有効なら http://PCの名前:4096 でもつながります。

スマートフォンの Tailscale アプリがオンになっている間は、モバイル回線でもつながります。

HTTPS で使いたい場合は、OpenCode を --hostname 127.0.0.1 で起動し、PC で tailscale serve --bg 4096 を実行すると、https://PCの名前.tailnet名.ts.net でつながります。

Cloudflare Tunnel でつなぐ

Tailscale を入れられない環境向けです。PC から Cloudflare に向けてトンネルを張り、インターネット上の HTTPS のアドレスで公開します。

  1. PC に cloudflared を入れます。
  2. 上の手順でサーバーを起動します（--hostname 127.0.0.1 でも構いません）。
  3. 別のターミナルで次を実行します。
    cloudflared tunnel --url http://localhost:4096
  4. 表示された https://〜.trycloudflare.com のアドレスをアプリに入力して接続します。

この方法では、アドレスを知っている人なら誰でもサーバーに届きます。パスワードは長く推測されにくいものにしてください。アドレスは起動するたびに変わります。固定のアドレスで使い続けたい場合は、Cloudflare のアカウントで名前付きトンネルを作成してください。

SSH のポート転送でつなぐ

すでに PC へ SSH で入れる環境がある人向けです。スマートフォンの SSH アプリ（Termius など）でポート転送を設定します。

  1. PC では OpenCode を --hostname 127.0.0.1 で起動します。
  2. SSH アプリでローカルポート転送を作ります。スマートフォン側のポート 4096 を、PC 側の 127.0.0.1:4096 に転送します。
  3. 転送を開始したまま、アプリで http://127.0.0.1:4096 に接続します。

SSH アプリがバックグラウンドに回ると転送が止まることがあります（特に iPhone）。普段使いには Tailscale のほうが安定します。

うまくいかないとき

プロジェクト一覧の右上にある「接続の診断」ボタンで、サーバーの応答、リアルタイム更新、通知プラグイン、MCP の状態をまとめて確認できます。結果はコピーしてお問い合わせに貼り付けられます。

Pocket Agent は OpenCode の公式アプリではありません。
