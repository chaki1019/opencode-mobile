プライバシーポリシー

Pocket Agent（以下「本アプリ」）　制定日: 2026年10月3日　改定日: 2026年10月8日

本アプリは、利用者が自分で用意した OpenCode サーバーにスマートフォンから接続するためのアプリです。このポリシーでは、本アプリが扱う情報と、その送り先を説明します。

1端末の中だけに保存する情報

  • 接続先サーバーの URL、ユーザー名、パスワード
  • 表示言語やテーマなどの設定、その日の無料メッセージ数、「広告を外す」の購入状態
  • 通知のペアリングキー

これらは端末の安全な保存領域（iOS のキーチェーン、Android の暗号化ストレージ）に保存し、開発者には送信しません。

2利用者の OpenCode サーバーとの通信

チャットの内容、添付した画像、ファイル、ターミナルの入出力は、本アプリから利用者が指定したサーバーへ直接送受信します。開発者のサーバーを経由することはなく、開発者がこれらを見ることはできません。

同じネットワーク内のサーバーを探すため、ローカルネットワーク（mDNS）を検索することがあります。検索結果は端末の外に送りません。

会話モードと読み上げでは、端末に備わっている音声認識と音声合成の機能（OS が提供するもの）を使います。音声認識では、OS の仕組みにより音声が Apple または Google などの OS 提供元のサービスで処理されることがあります。本アプリは録音した音声を保存せず、開発者にも送信しません。文字にした内容は、チャットと同じく利用者のサーバーにだけ送ります。

3プッシュ通知

通知を有効にすると、次の情報を開発者が運営する通知中継サーバー（Cloudflare Workers 上で動作）に登録します。

  • 端末の通知トークン（Firebase Cloud Messaging が発行するもの）
  • OS の種類（iOS / Android）と登録日時
  • ペアリングキーから作った認証用の値（ハッシュ化して保存）

通知の本文（プロジェクト名やセッション名）は端末側でしか復号できない形で暗号化されており、中継サーバーや開発者は内容を読めません。中継サーバーが知るのは、通知の種類（完了、失敗、確認待ちなど）だけです。

登録は、アプリで通知をオフにしたとき、ペアリングを解除したとき、またはアプリの削除などで通知トークンが無効になったときに削除されます。

通知の配信には Google の Firebase Cloud Messaging と、iOS では Apple Push Notification service を利用します。

4広告

本アプリは Google AdMob による広告を表示します。AdMob は広告の表示と効果測定のため、広告 ID（iOS の IDFA、Android の広告 ID）、IP アドレス（およその地域の推定に使われます）、端末やアプリの情報、広告の表示・タップの状況などを収集することがあります。

  • 欧州経済領域・英国などでは、起動時に Google のツールで同意を確認します。「設定」→「広告のプライバシー設定」から選択をやり直せます。
  • iOS では、トラッキングを許可した場合だけ IDFA が使われます。
  • 「広告を外す」を購入すると広告は表示されなくなり、次回の起動からは広告 SDK も起動しません。

詳しくは Google のパートナーのサイトやアプリでのデータ使用 をご覧ください。

5アプリ内課金

「広告を外す」の購入は App Store または Google Play を通じて行われます。支払い情報は Apple または Google が扱い、開発者は受け取りません。

6クラッシュレポート

本アプリが異常終了したとき、原因を調べるために Google の Firebase Crashlytics へ次の情報を送ります。

  • エラーの内容とスタックトレース
  • 端末の機種、OS のバージョン、アプリのバージョン、空きメモリなどの状態
  • Crashlytics がアプリのインストールごとに発行する識別子

チャットの内容やサーバーの接続情報は含めません。「設定」→「クラッシュレポートを送信」をオフにすると送信を止められます。

7利用状況の分析

本アプリを改善するため、Google の Firebase Analytics で利用状況の統計を取ります。送る情報は次のとおりです。

  • インストール、起動、利用した日時と時間
  • 開いた画面の種類（「設定」「チャット」など。プロジェクト名、セッション名、ID は含めません）
  • 端末の機種、OS のバージョン、アプリのバージョン、言語、IP アドレスから推定したおよその地域
  • Firebase Analytics がアプリのインストールごとに発行する識別子

広告 ID（iOS の IDFA、Android の広告 ID）と IDFV は使わず、広告やトラッキングには使いません。チャットの内容やサーバーの接続情報も含めません。開発者は個人を特定しない集計結果だけを見ます。

あわせて、Microsoft Clarity で画面の操作を記録し、使いにくい画面を見つけるのに使います。送る情報は次のとおりです。

  • 画面の配置と、タップやスクロールなどの操作
  • 開いた画面の種類（上と同じく、プロジェクト名、セッション名、ID は含めません）
  • 端末の機種、OS のバージョン、アプリのバージョン、IP アドレスから推定したおよその地域
  • Clarity がアプリのインストールごとに発行する識別子

記録では、アプリの設定画面を除くすべての画面の文字と画像を隠して送ります。チャットの内容、コード、ターミナルの出力、サーバーの URL やパスワード、入力した文字は記録に残りません。広告 ID は使わず、広告やトラッキングには使いません。

「設定」→「利用状況を送信」をオフにすると、Firebase Analytics と Microsoft Clarity のどちらの送信も止められます。

8アップデートの確認

起動時に、利用できる最低バージョンを通知中継サーバーに問い合わせます。この通信で送るのは通常のインターネット通信に伴う情報（IP アドレスなど）だけで、利用者を特定する情報は送りません。

9第三者への提供

上記のサービス提供者（Google、Apple、Cloudflare、Microsoft）による処理を除き、法令に基づく場合を除いて、取得した情報を第三者に提供しません。

  • Google プライバシーポリシー（AdMob、Firebase）
  • Apple プライバシーポリシー
  • Cloudflare プライバシーポリシー
  • Microsoft プライバシーに関する声明（Clarity）

12このウェブサイトのアクセス解析

このウェブサイト（opencodemobile.app）では、見られているページを知るために Cloudflare Web Analytics を使っています。Cookie や端末の保存領域は使わず、閲覧者を識別する情報も作りません。集めるのは、開いたページの URL、どのページから来たか、ブラウザと OS の種類、IP アドレスから推定した国、ページの表示速度で、開発者は集計結果だけを見ます。Cloudflare はこの情報を広告には使いません（Cloudflare のプライバシーポリシー）。

あわせて、ページのどこが読まれ、どこで離れているかを知るために Microsoft Clarity を使っています。Clarity は Cookie を使い、次の情報を Microsoft に送ります。

  • 開いたページ、クリック、スクロール、マウスの動き（ページ上の操作の再現と、よくクリックされる場所の集計に使います）
  • ブラウザ、OS、画面の大きさ、IP アドレスから推定したおよその地域
  • Clarity がブラウザごとに発行する識別子

このウェブサイトには入力欄がなく、Clarity が入力内容を受け取ることはありません。開発者は広告やトラッキングには使いません。Clarity の Cookie は、ブラウザの設定で削除したりブロックしたりできます（Microsoft プライバシーに関する声明）。
